# Personal Portfolio Website - Tejas Gupta

Minor project (Web Development): a simple, responsive personal portfolio.

## Structure
- Pages/sections: Home, About, Projects, Contact
- `index.html` - page content and SEO meta tags
- `style.css` - styling, Flexbox/Grid layout, mobile breakpoint at 768px
- `script.js` - project cards, skills, mobile menu, contact form validation
- `images/tejas.jpg` - profile photo

## Workflow
1. Defined the objective: show skills, projects and background.
2. Planned four sections and sketched a single-page layout.
3. Chose a light theme, blue accent, and system fonts for speed.
4. Built with HTML, CSS and JavaScript (no frameworks).
5. Made it responsive with Grid and Flexbox.
6. Added project cards (from a JS array) and a validated contact form.
7. Tested on phone and desktop and in Chrome and Firefox.
8. Optimized: small image, no libraries, meta description, alt text, semantic tags.
9. Deployed on GitHub Pages.

## Design decisions
- Single page with smooth scrolling keeps navigation simple.
- Projects are stored in one array so adding one takes a few lines.
- Contact form opens the visitor's email app, so no backend is needed.

## Deploy on GitHub Pages
1. Create a repo (e.g. `Personal-Portfolio-Website`) and upload all files.
2. Settings > Pages > Source: `main` branch, `/ (root)`.
3. Your site goes live at `https://dev-tejas07.github.io/Personal-Portfolio-Website/`.

## Run locally
Open `index.html` in a browser.
